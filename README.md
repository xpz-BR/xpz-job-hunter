> **Job-Hunter** é uma plataforma inteligente e open source para busca de vagas de emprego em **todas as áreas profissionais** (Administração, Recursos Humanos, Logística, Vendas, Tecnologia, Operacional e muito mais). O sistema calcula em tempo real a **porcentagem exata de compatibilidade (% Match)** com seu perfil, turno desejado e nível de experiência.

---

## 🌟 O Que Há de Novo (v2.0)

- 🏢 **Suporte a Todas as Categorias do Mercado:**
  - Administração & Finanças
  - Recursos Humanos (RH & DP)
  - Logística, Armazém & Estoque
  - Vendas, Atendimento & Marketing
  - Tecnologia & Programação
  - Serviços Gerais & Operacional
- ⚡ **Seleção Pré-Definida em 1 Clique (Estilo LinkedIn):**
  - Chega de digitar textos longos! Selecione sua área e marque suas competências e cargos em uma nuvem interativa de opções prontas (com opção de adicionar personalizadas).
- ⏰ **Filtro de Carga Horária & Turnos:**
  - Escolha se deseja trabalhar no turno da **Manhã (Matutino)**, **Tarde (Vespertino)**, **Noite (Noturno)**, **Integral (Comercial)** ou **Escala 12x36 / 6x1**.
- 🎓 **Filtro por Tipo de Contrato:**
  - Vagas dedicadas para **Menor / Jovem Aprendiz**, **Estágio**, **CLT**, **PJ** e **Temporário**.
- 🛡️ **Filtro Rígido de Nível (Senioridade):**
  - Garante precisão absoluta nas pesquisas: se você busca vagas **Júnior**, **Estágio** ou **Aprendiz**, vagas de nível Sênior/Lead/Especialista são automaticamente descartadas.

## 🚀 Como Executar Localmente

### 1. Clonar o Repositório
```bash
git clone https://github.com/xpz-BR/xpz-job-hunter.git
cd xpz-job-hunter
```

### 2. Ativar o Ambiente Virtual e Instalar Dependências
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
```

### 3. Rodar a Aplicação
```bash
python run.py
```

Acesse:
- 🌐 **Painel Web:** [http://localhost:8000](http://localhost:8000)
- 📖 **Documentação Swagger:** [http://localhost:8000/docs](http://localhost:8000/docs)
